General
Ctrl + N New project
Ctrl + O Open project
Ctrl + S Save project
Ctrl + Shift + S Save project as
Ctrl + I Import media file
Ctrl + Shift + C Open camera device
Ctrl + Shift + A Add color source
Ctrl + Shift + Y Add Syphon source (macOS)
Ctrl + , Open preferences
Ctrl + K Keyboard shortcuts
Ctrl + Q Quit MapMap
Editing
Alt + S Sticky vertices
Ctrl + Z Undo
Ctrl + Shift + Z Redo
Ctrl + D Duplicate layer
Delete Delete layer
F2 Rename layer
H Flip horizontally (in the input view: flip the image inside the layer)
V Flip vertically (in the input view: flip the image inside the layer)
Shift + R Rotate 90° clockwise (in the input view: rotate the image inside the layer)
Shift + L Rotate 90° counterclockwise (in the input view: rotate the image inside the layer)
Page Up Raise layer
Page Down Lower layer
Home Raise layer to top
End Lower layer to bottom

Alt + U Show/Hide undo history

Alt + L Open console window
Ctrl + 1 Main layout
Ctrl + 2 Input editor layout
Ctrl + 3 Output editor layout
Ctrl + + Zoom in
Ctrl + - Zoom out
Ctrl + 0 Original size
Layers & shapes
Ctrl + M Add quad layer
